# Gas Characteristics

Approximate gas costs below are taken directly from the Hardhat gas snapshot files copied into
`test/gas/.hardhat-snapshots/` (produced by `test/gas/WeightedPoolBenchmark.test.ts`). These are recorded gas
snapshot values from the benchmark suite (`[WeightedPool - *]` snapshot entries), not re-measured
in this repo. They are approximate and will drift with compiler/optimizer settings and Vault version.

"Standard" = tokens with `TokenType.STANDARD` (no rate provider). "WithRate" = one or more tokens using an external
rate provider (extra rate-fetching overhead). "ERC4626" = swaps routed through ERC4626 buffer-aware paths.

## Pool creation

No gas snapshot exists for `WeightedPoolFactory.create()` itself in the copied benchmark suite (the snapshots cover
swap/add/remove/initialize operations on an already-deployed pool, not the `create()` call). Qualitatively:
`WeightedPoolFactory.create()` deploys a `WeightedPool` via `CREATE2`/`CREATE3` (through `BasePoolFactory._create`),
computes `minTokenBalances` for each token (an external `decimals()` call per token), and registers the pool with
the Vault. Expect creation gas to scale roughly linearly with token count (2–8 tokens), since the constructor loops
over tokens to validate and store weights/min-balances.
