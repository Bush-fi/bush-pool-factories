# bush-maths

Exact fixed-point reference maths for Bush Protocol pools, in TypeScript, Python and Rust. Forked from
[balancer-maths](https://github.com/balancer/balancer-maths) (MIT), trimmed to the pool types deployed by the
factories in this repository, and adjusted where Bush's contracts differ (for example `WeightedPool`'s
rounding of the token-in balance and its per-token minimum balances).

| Package | Where |
| --- | --- |
| `@bush.fi/maths` (TypeScript, `bigint`) | [typescript/](./typescript) |
| `bush-maths` (Python, `int`) | [python/](./python) |
| `bush-maths` (Rust, `U256`) | [rust/](./rust) |

Each package has a `Vault` that reproduces the on-chain Vault flow — token scaling and rates, swap fees, hook
calls, add/remove liquidity maths — on top of per-pool-type classes, so its results are the raw amounts the
Router returns:

| `poolType` | Factory | Notes |
| --- | --- | --- |
| `WEIGHTED` | weighted-pool-factory | |
| `WEIGHTED_8020` | weighted-8020-pool-factory | same `WeightedPool` contract |
| `COW` | cow-pool-factory | same `WeightedPool` contract; CowRouter fee split in `cow/` |
| `STABLE` | stable-pool-factory | |
| `STABLE` + `StableSurge` hook | stable-surge-pool-factory | |
| `LIQUIDITY_BOOTSTRAPPING` | lbpool-factory | seeded LBPs only |
| `FIXED_PRICE_LBP` | fixed-price-lbpool-factory | |

## Test data

[testData/](./testData) holds one file per pool generated by [check/](./check): a pool
created through its factory on a local chain, its full state, and the results of swaps / adds / removes queried
through the Router. All three test suites read every file in that directory and assert exact equality:

```
cd typescript && npm test
cd python     && python3 -m pytest
cd rust       && cargo test
```

Regenerate with `npm run maths:generate` at the repository root.

## Adding a pool type

New pool maths is written directly into these packages (the pool class and its state type in each language),
registered in [check/](./check) and checked against the deployed contract with `npm run maths:check`; see
[CONTRIBUTING.md](../CONTRIBUTING.md). Once it matches, the `poolType` is added to each `Vault` and the test
readers' state mapping so the suites here cover its test data too. The `ConstantSum` pool in each package is the
template's example, not a Bush pool type.
